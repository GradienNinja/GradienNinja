## Featured Work

### Bank Customer Loan Acceptance Prediction
A classification project predicting whether bank customers will accept personal loan offers.

- **Dataset**: 5,000 customer records, 14 features
- **Models**: Decision Tree (98% accuracy), SVM with RBF kernel
- **Best Performance**: Decision Tree with 87% recall on positive class
- **Key Insight**: Income and credit card spending are strong predictors; Age and Experience are redundant features

[Repository](https://github.com/GradienNinja/Bank-Customer-Loan-Acceptance)
